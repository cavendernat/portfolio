# Nathan Cavender Portfolio

Static portfolio site for GitHub Pages.

## Run locally
Open `index.html` directly, or serve the folder with any static web server.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your default branch and `/ (root)`.
6. Save. GitHub will provide the public site URL.

## Structure
- `index.html` — homepage
- `projects/` — project case studies
- `assets/style.css` — site styles
- `resume/` — downloadable resume

## Before publishing
- Add your GitHub and LinkedIn URLs if desired.
- Replace abstract project visuals with screenshots when available.
- Verify the public resume contains only contact information you want online.
- Never commit API keys or other secrets.

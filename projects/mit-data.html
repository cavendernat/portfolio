Context

During my National Center for Data Services internship, I collaborated on data curation and analysis for an MIT Libraries DSpace repository project. The work used visitor logs and download data to better understand system usage.

Work performed

I cleaned and analyzed repository datasets and contributed to analysis of user behavior and system-use patterns. The internship also provided practical experience in data management, curation, and communicating findings with project stakeholders.

What this demonstrates

This project complements my AI work because it starts with a more fundamental analytics problem: turning operational logs into trustworthy, interpretable evidence. It required attention to data quality, behavioral signals, and the limits of what usage data can actually support.
